# 計算機程式設計 - 圖書借閱系統 (HW8)

## 題目目標

整合開發「會員管理模組」與「借閱管理模組」，建構一個具備多功能、強健異常防錯機制的圖書借閱與歸還交易系統。

---

## 系統規定整理

### 1. 主模組流程

- 可持續輸入模組代號以進行系統切換。
- 模組代號 `1`：進入**會員管理模組**，輸出 `Use member function`。
- 模組代號 `2`：進入**借閱管理模組**，輸出 `Use borrow function`。
- 模組代號 `-1`：結束程式，輸出 `Goodbye`。
- 其他任意模組代號：輸出 `No such command`。

### 2. 會員管理模組流程 (`member_management`)

- 進入後可持續輸入功能代號以執行會員操作。
- 若功能代號**不屬於 `1~5`**：退出會員管理模組，輸出 `Exit member function`。
- 各功能代號對應如下：
  - `1` **新增會員**：輸入 `會員ID 姓名 電話 地址`
    - 若 ID 重複 ➡️ 輸出 `ID duplicated`
    - 成功建立 ➡️ 輸出 `Creation successful`
  - `2` **修改會員**：輸入 `會員ID 欄位編號 新資料` (欄位編號 1=姓名, 2=電話, 3=地址)
    - 若 ID 不存在 ➡️ 輸出 `No such ID`
    - 修改成功 ➡️ 輸出 `會員ID 姓名 電話 地址`
  - `3` **刪除會員**：輸入 `會員ID`
    - 若 ID 不存在 ➡️ 輸出 `No such ID`
    - 成功刪除 ➡️ 輸出 `Deletion successful`
  - `4` **查詢會員**：輸入 `會員ID`
    - 若 ID 不存在 ➡️ 輸出 `No such ID`
    - 查詢成功 ➡️ 輸出 `會員ID 姓名 電話 地址`
  - `5` **查詢全部會員**：依 ID 由小到大輸出，每行格式為 `會員ID 姓名 電話 地址`

### 3. 借閱管理模組流程 (`borrow_management`)

- 進入後可持續輸入功能代號以執行借還書操作。
- 若功能代號**不屬於 `1~5`**：退出借閱管理模組，輸出 `Exit borrow function`。
- 各功能代號對應如下：
  - `1` **借閱書籍**：輸入 `書籍ID 會員ID`
    - 會員 ID 不存在 ➡️ 輸出 `No such member ID`
    - 書籍 ID 不存在 ➡️ 輸出 `No such book ID`
    - 書籍已被他人借閱 ➡️ 輸出 `Not returned yet, 書籍ID is borrowed by 借閱會員ID_會員名稱`
    - 借閱成功 ➡️ 輸出 `書籍ID is borrowed by 借閱會員ID_會員名稱`
  - `2` **歸還書籍**：輸入 `書籍ID`
    - 書籍 ID 不存在 ➡️ 輸出 `No such book ID`
    - 書籍尚未被借閱 ➡️ 輸出 `No such transaction`
    - 歸還成功 ➡️ 輸出 `書籍ID is returned by 借閱會員ID_會員名稱`
  - `3` **查詢會員借閱清單**：輸入 `會員ID`
    - 會員 ID 不存在 ➡️ 輸出 `No such member ID`
    - 會員存在：先輸出 `會員ID 會員名稱`
      - 若該會員無任何借閱書籍 ➡️ 輸出 `None`
      - 若有借閱 ➡️ 依書籍順序輸出已借閱之 `書籍ID 書籍名稱`
  - `4` **查詢單一書籍資訊**：輸入 `書籍ID`
    - 書籍 ID 不存在 ➡️ 輸出 `No such book ID`
    - 若已被借閱 ➡️ 輸出 `書籍ID 書籍名稱(借閱會員ID_會員名稱)`
    - 若尚未借閱 ➡️ 輸出 `書籍ID 書籍名稱`
  - `5` **查詢所有書籍資訊**：依書籍順序輸出所有 20 本書籍資料：
    - 已被借閱 ➡️ 輸出 `書籍ID 書籍名稱(借閱會員ID_會員名稱)`
    - 尚未借閱 ➡️ 輸出 `書籍ID 書籍名稱`

---

## 欄位規格與資料限制

- **會員資料**：
  - 會員ID：整數（`0` ~ `99` 為合法範圍）
  - 姓名：10 字元以內（無空白）
  - 電話：10 字元以內（無空白）
  - 地址：50 字元以內（無空白）
  - 系統會員上限：100 人
- **書籍資料**（預設 20 本）：
  - 書籍 ID 包括 B01~B10 與 B001~B010。
  - 預設狀態為「未借出 (`BookStatus == 1`)」，借閱者為 `-1`。

---

## 專案檔案結構

- `main.c`：主程式（包含會員與借閱管理功能實作）
- `input.txt`：多功能交互測試輸入檔
- `output.txt`：最近一次執行的實際輸出結果

---

## 測試與執行指南

### 1. 編譯

```bash
gcc main.c -o main.exe
```

### 2. 依測資 input.txt 執行重導向輸出

使用 Windows CMD 進行重導向：
```bash
cmd /c "main.exe < input.txt > output.txt"
```

使用 PowerShell 進行重導向：
```powershell
cmd.exe /c ' "main.exe" < input.txt > output.txt '
```
